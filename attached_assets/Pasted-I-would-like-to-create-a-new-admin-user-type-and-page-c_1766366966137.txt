I would like to create a new admin user type and page/control panel on the main website. The admin page would essentially be a LIMS for specimen tracking and results reporting. Key menu items:

Pending Shipments
Would show all of the pending shipments that users have submitted. It would show the user's name, State, and the total number of specimens. Clicking the shipment would being up a view showing all of the items on the shipment. Admins would have the option to mark as Shipment Received using a button next to it. That would update the shipment status on the users profile "Shipment received, pending tissue extraction". There should also be a button for "Sent to Indiana" with would update the status to "Shipment received, sent to Indiana for tissue extraction" - For both of these the individual lines on the users shipment would show Pending Tissue. The longer status would be at the top of the shipment.

Build a Run

There would be 20 boxes on the screen labeled "Plate 1" to "Plate 20" clicking on each of the individual plates would bring up a screen similar to that we have for adding bags on the user profile shipment page. One of the key reasons I would like a spreadsheet rather than individual fields is so I can drag and drop cells down to fill a series. Ex - IN01, IN02, IN03, so the spreadsheet library should have the ability to do this.
